# 人工校订的词组读音
#
# 背景：data/phrase_pinyin.txt 来自 mozillazg/phrase-pinyin-data，读音大多正确，
# 但多音字的词义区分有成片的遗漏。「朴」「差」「骨」这类整族错误，以及
# 「漯河 tà hé」与同表「漯河市 luò hé shì」自相矛盾的条目，都属于这一类。
#
# 收录标准（三条同时满足）：
#   1. 校订后的读音是《现代汉语词典》意义上的唯一标准读法；
#   2. 该读音确实属于该字（见 dict_data.go 里该字的读音列表）；
#   3. 能在常用词中验证（见每条的说明）。
#
# 有意不收录的情况：
#   - 一/不 的变调（一刀两断 yì dāo、不对 bú duì 之类）。源表按变调标注，
#     本库也按变调输出，两边都对，不是错误；与 CC-CEDICT「一 一律标 yī」的
#     差异属标注惯例。
#   - 真正的异读（上调 shàngdiào/shàngtiáo、供养 gòngyǎng/gōngyǎng、
#     斗牛 dòuniú/dǒuniú、运转 之外的 卷 juàn/juǎn 等）：各词典分歧，保持原样。
#   - 轻声的书写差异（豆腐 dòu fu 写成 dòu fǔ 之类）：属标注惯例。
#   - 姓氏（单 shàn、仇 qiú、解 xiè 等）：源表基本都按常用音处理，本库不做姓氏
#     识别，改用词表覆盖不现实，留待调用方自行处理。
#
# 每条都会被 cmd/gendata 严格校验：词组必须在源表中存在、音节数与字数一致、
# 音节规范、且校订后的读音确实与源表不同。任何一条不满足都会终止生成，
# 避免校订表悄悄失效。
#
# 格式：词组: 读音 读音 ...  # 说明
