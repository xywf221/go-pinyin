# 人工校订的默认读音
#
# 背景：pinyin.txt 的默认读音取自 Unihan kMandarin 字段。绝大多数情况下它是正确的，
# 但存在少量明显错误——通常是把罕见读音排在了常用读音前面。
#
# 收录标准（三条同时满足）：
#   1. 汉典 zdic.net、现代汉语词典(kXHC1983)、通用规范汉字字典(kTGHZ2013) 三方一致；
#   2. 该读音确实出现在 pinyin.txt 的读音列表中；
#   3. 能在常用词中验证（见每条的例词）。
#
# 未收录的争议字说明：
#   - 重、长、行 等：各来源本身分歧，且词频数据支持当前默认音，保持不动。
#     它们的问题属于词组层面（重庆/长沙/银行），不是单字读音错误。
#   - 万、且、区 等：现汉把姓氏、生僻义排在前面，当前默认音才是常用音，保持不动。
#
# 格式：U+XXXX: 读音  # 汉字  —— 例词
